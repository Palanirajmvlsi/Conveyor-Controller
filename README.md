## 📱 Mobile Application

The **Conveyor Controller App** provides a mobile interface for monitoring and controlling the industrial conveyor system.

### Application Functions

- Conveyor control
- Production monitoring
- Status monitoring
- Real-time system interaction

### App Package

The Android App Bundle is provided as **`app-release.aab`** in the repository.

---

## 🔧 Customized IoT Control Board

The system uses a customized ESP32-S3-based PCB for industrial conveyor monitoring and control.

### Hardware

- ESP32-S3-WROOM-1
- Sensor input interfaces
- Output control interfaces
- Power management
- Industrial connectors
- USB interface
